# Changelog — IronLog

## [1.6.0] - 2026-06

### Added
- Workout creation flow with 4-level drill-down navigator
- Exercise database (100+ exercises, 11 categories)
- Bottom-sheet set logging with rep/weight steppers
- 1RM estimation (Epley formula)
- Warm-up generator
- PR auto-detection with toast notifications
- Session history with weekly/monthly review
- 12-week adherence grid
- Body weight tracking with Chart.js trend chart
- Body fat percentage tracking with goal prediction
- Muscle map (SVG front/back) with coverage heatmap
- Nutrition tracking with macro goals
- Water intake tracker
- Settings page (units, profile, goals)
- PWA-ready (service worker, manifest)
- Dark theme
- Responsive design (sidebar desktop, bottom nav mobile)
- Custom program loader
- Onboarding flow
- Rest timer with ring visualization
- Post-workout stretch timer
- Coach engine with personalized suggestions
- Goal center with progress tracking
